## 📐 What This Folder Is For
Named minor NPCs who fit anywhere — the names that turn up in player-character backstories, epigraphs, rumours and one-off scenes. Each gets a short note so the name is **recorded and canon**, but is left **open enough to grow hooks later**.

Conventions for every note in this folder:
- **One note per named person.** Unnamed relatives stay unnamed until play needs them; list them as open hooks instead.
- **Register first.** Pick the name from its register (Reference - Name Tables). A name drawn from a table is marked *allocated* there, with its parent.
- **In-world voice.** Write what people say and believe. Ground truth, if a minor NPC ever gets any, goes in a `> **GM-facing.**` callout.
- **Keep it thin.** Fill only what is established. Everything else goes under **Open hooks**, phrased as a question.
- **Say who introduced them** (a PC backstory, a note, a session), so the source stays traceable.
- **Log it.** Add a row to the canon tracker's NPC table.
