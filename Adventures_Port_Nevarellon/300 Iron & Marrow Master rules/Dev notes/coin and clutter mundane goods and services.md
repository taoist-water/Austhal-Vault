# Coin and Clutter: Mundane Goods & Services

_A conversion of the classic "Goods and Services" and "Armor and Shields" tables into Iron & Marrow terms._

## Conversion Philosophy (Read This First)

This is **not** a gp-to-sp currency conversion. If it were, a suit of Full Plate would cost 1,500 sp instead of the 200 sp already printed in _Hardware_, and every price in this document would contradict the core book on sight. Instead, every item below is priced by **analogy** — anchored against what's already established:

- **Currency:** sp is the base unit. cp for anything trivial (10 cp = 1 sp). gs only for the handful of items that are genuinely nobility/cartel-tier purchases (per the existing "gold is held only by nobility and wealthy cartels" fluff).
- **Availability bands = price bands.** I'm using the bands _Soothing the Soul_ already defined for Acquisition, since they're the only official price logic in the system: **Common 1–25 sp, Scarce 15–50 sp, Rare 50–200+ sp, Legendary GM-set.** Everything below was slotted into these bands rather than mathematically derived.
- **Slots follow the existing sizing logic exactly** — 0 Slots for pocket clutter, 1 Slot for standard gear, 2 Slots for bulky/awkward gear (per _Hardware_'s Visual Slot System). I did not invent a new slot tier.
- **No new subsystems.** Where an item has no obvious mechanical hook, it stays flavor-only. Most of what follows is texture, not a lever the dice touch — that's consistent with the system's stated goal of reducing cognitive load.
- **Overlap check first.** Several d20 items already have a mechanically-identical twin in _Hardware_. Where that's true, I say so and don't create a duplicate entry.

One flagged item needs your sign-off before it's real: a proposed expansion of the core Armor table (Section 9). Everything else here is safe to treat as final.

## 0. Two Rules Clarified During This Exercise

Both of these resolve real ambiguity in the core system rather than just this equipment list — worth considering for _Hardware_'s Inventory section proper, even though I'm formalizing them here for now.

### 0a. What the Community Supply Die Actually Tracks

_Hardware_ abstracts the party's shared consumables into the Die so nobody tracks individual arrows, torches, or waterskins. Concretely, that's:

- **Ammunition** — arrows, bolts, sling stones, thrown weapons you don't bother retrieving.
- **Light & Fuel** — torch stubs, lantern oil, flint-and-steel strikes, tindertwigs.
- **Field Rations & Water** — trail rations, waterskin refills.
- **Field Medicine** — the bandages and clean linen that make a Breather actually work. This is why a Depleted die specifically blocks Breathers from clearing Dissonant Stress — there's nothing left to bind the wounds with.

**The dividing line for anything new that comes up later:** if it's _used up in the doing_ — an arrow loosed, oil burnt, a ration eaten, a bandage wound around a cut — it's the Die's problem. If it _still exists and still works_ after you use it — a bow, a lantern, a crowbar, a coil of rope — it's a normal Slotted item, tracked individually as in Section 1.

**Does the Die itself take a Slot?** No. It isn't a discrete object on any one character's sheet — it's already distributed as flavor across everyone's belts and packs collectively. Don't write "1× Supply Die" under anyone's inventory.

**Replenishing it**, via the existing Acquisition Downtime Pursuit (_Soothing the Soul_):

| Step                             | Cost            |
| -------------------------------- | --------------- |
| Depleted → d4                    | 5 sp            |
| d4 → d6                          | 10 sp           |
| d6 → d8                          | 15 sp           |
| d8 → d10                         | 20 sp           |
| **Full restock, Depleted → d10** | **50 sp total** |

Resolved as a single Half-day Acquisition action (Influence or Survival vs. TN 8, Common-tier goods) — Settlement Tier and Reputation modifiers apply normally (a Hostile settlement can refuse outright; a Hamlet's -2 still bites). This is the "civilized" counterpart to the Scrounger's _Scavenge and Cannibalize_ Momentum spend, which does the same +1 step mid-dungeon for 2 Momentum instead of coin.

### 0b. Containers Don't Multiply Slots

A container's listed Slot cost is for **the object itself**, full stop. Owning one never grants extra carrying capacity — it isn't a nested storage space, it's an item like any other. If it worked that way, one 2-Slot chest would let a character haul unlimited gear for a single purchase, and the Attrition Tax (Wounds forcing you to drop gear) evaporates the moment anyone thinks to buy a box.

**What decides whether an _empty_ container costs a Slot at all:**

- **Rigid/bulky-shaped** containers (Basket, Chest, Barrel) hold their shape and bulk whether full or empty, so they cost their listed Slots regardless of contents.
- **Soft/collapsible** containers (Sack, Belt Pouch, the Backpack itself) fold to nothing when unstuffed, so they're 0 Slots — until something with its own Slot cost goes inside, at which point you're tracking _that item's_ cost, not an extra charge for the sack around it.

**On _Hardware_'s existing "small treasure chest" example (2 Slots):** that's a _found-loot_ abstraction — chest-plus-contents collapsed into one carry-out object hauled from a dungeon, not an empty container a character buys and refills over a campaign. Same underlying rule (rigid object, fixed Slot cost), different use case, so it doesn't actually contradict anything — it just wasn't spelled out until now.

**The Backpack** (Section 1) is still 0 Slots and worn-exempt, but to be explicit: it doesn't add capacity either. It's the fictional wrapper for the Pack designation, not a bag of holding — the Pack's actual size is fixed entirely by the character's Prowess-derived Slot total, independent of what container physically holds it.

**A seam worth flagging while I built this table:** _Manipulating the Void_ uses **Novice / Adept / Master** for Arcana spell levels, while _Embracing the Abyss_'s Domain of Law Miracles use **Novice / Apprentice / Master**. Same three tiers, different word for the middle one across two documents. Not urgent, but worth a pass to pick one term for "tier 2" and use it everywhere — right now a GM reading both books back to back has to mentally reconcile "Adept" and "Apprentice" as the same rung.

Reintroducing a separate numeric penalty stack on top of that would just recreate the exact granular bookkeeping the system was built to avoid. Leave it alone.
