# Coin and Clutter: Mundane Goods & Services
*A conversion of the classic "Goods and Services" and "Armor and Shields" tables into Iron & Marrow terms.*

## Conversion Philosophy (Read This First)

This is **not** a gp-to-sp currency conversion. If it were, a suit of Full Plate would cost 1,500 sp instead of the 200 sp already printed in *Hardware*, and every price in this document would contradict the core book on sight. Instead, every item below is priced by **analogy** — anchored against what's already established:

- **Currency:** sp is the base unit. cp for anything trivial (10 cp = 1 sp). gs only for the handful of items that are genuinely nobility/cartel-tier purchases (per the existing "gold is held only by nobility and wealthy cartels" fluff).
- **Availability bands = price bands.** I'm using the bands *Soothing the Soul* already defined for Acquisition, since they're the only official price logic in the system: **Common 1–25 sp, Scarce 15–50 sp, Rare 50–200+ sp, Legendary GM-set.** Everything below was slotted into these bands rather than mathematically derived.
- **Slots follow the existing sizing logic exactly** — 0 Slots for pocket clutter, 1 Slot for standard gear, 2 Slots for bulky/awkward gear (per *Hardware*'s Visual Slot System). I did not invent a new slot tier.
- **No new subsystems.** Where an item has no obvious mechanical hook, it stays flavor-only. Most of what follows is texture, not a lever the dice touch — that's consistent with the system's stated goal of reducing cognitive load.
- **Overlap check first.** Several d20 items already have a mechanically-identical twin in *Hardware*. Where that's true, I say so and don't create a duplicate entry.

One flagged item needs your sign-off before it's real: a proposed expansion of the core Armor table (Section 9). Everything else here is safe to treat as final.

### 1a. Locks (Thievery Interaction)

D&D's Simple/Average/Good/Superior lock ladder maps directly onto the Situational Modifier framework *Tools for the Nameless* already defines — no new mechanic needed, just a price/difficulty table.

| Lock Quality | Bypass Modifier | Cost | Availability |
|---|---|---|---|
| Simple | Standard (+0) | 5 sp | Common |
| Average | Difficult (-2) | 20 sp | Common |
| Good | Extreme (-4) | 45 sp | Scarce |
| Superior | Extreme (-4) **and** Disadvantage | 90 sp | Rare |

*Ghost in the Machine (Tier 3 Feat) already bypasses any lock regardless of quality — this table doesn't need a special case for it, it already just works.*

**Paying an NPC to cast a spell or perform a Miracle — new formula.** D&D's *caster level × spell level × 10 gp* has nothing to key off in Iron & Marrow (no "caster level" stat exists). I'm proposing a flat Level-tier price instead:

| Spell/Miracle Level | Price |
|---|---|
| Cantrip | 15 sp |
| Novice | 30 sp |
| Adept / Apprentice | 60 sp |
| Master | 120–150 sp |

*Resurrection is explicitly excluded from this table — at 8 Locked Stress cost to the caster and a Master Miracle to begin with, it should never be a walk-up shop purchase. Treat it as Commission-gated, if available at all.*

**A seam worth flagging while I built this table:** *Manipulating the Void* uses **Novice / Adept / Master** for Arcana spell levels, while *Embracing the Abyss*'s Domain of Law Miracles use **Novice / Apprentice / Master**. Same three tiers, different word for the middle one across two documents. Not urgent, but worth a pass to pick one term for "tier 2" and use it everywhere — right now a GM reading both books back to back has to mentally reconcile "Adept" and "Apprentice" as the same rung.

## 9. Armor & Shields — Mapping Table 6-6

This is the section that actually touches core mechanics, so I've kept it separate and conservative. Iron & Marrow deliberately runs four armor tiers instead of d20's ten — that's a design choice, not an oversight, so my default move below is **reskin**, not **invent**.

| d20 Armor | Iron & Marrow Equivalent | Treatment |
|---|---|---|
| Padded | Padded (+0, Cushioned) | Direct match |
| Leather | Leather (+1) | Direct match |
| Studded Leather | Leather (+1) | Reskin — fancier stitching, same niche, no new tier needed |
| Hide | Chainmail/Scale (+2, Bulky) | Reskin — "primitive" flavor variant |
| Scale Mail | Chainmail/Scale (+2, Bulky) | Direct match (literally the same name already) |
| Chainmail | Chainmail/Scale (+2, Bulky) | Direct match |
| Splint Mail / Banded Mail | Plate Armor (+4, Restricted) | Reskin |
| Full Plate | Plate Armor (+4, Restricted) | Direct match, already priced at 200 sp |
| Buckler | Buckler (2 SV, Nimble) | Direct match |
| Light/Heavy Wooden or Steel Shield | Kite/Round Shield (4 SV, Cover) | Reskin |
| Tower Shield | Tower Shield (5 SV, Bulwark, Obstructive) | Direct match |
| Armor spikes | New minor add-on | See below |
| Gauntlet, locked | New minor add-on | See below |
| Shield spikes | New minor add-on | See below |

**Everything above needs no sign-off — it's pure reskinning of what already exists.** Two d20 entries don't have a clean home, though:

### \[DESIGNER SIGN-OFF NEEDED\] Two Proposed New Armor Entries

- **Chain Shirt** — d20's "light but still +4 AC" niche has no I&M equivalent. Proposed: **+2 Armor, Light (no Bulky tag), 70 sp, Scarce.** Same protection as Chainmail/Scale, priced higher specifically because it *lacks* the Bulky penalty — you're paying for mobility, same logic Masterwork Quality already uses to price out negative-tag suppression.
- **Breastplate** — d20 carves out a "heavy medium" niche between Chainmail and full Plate. Proposed: **+3 Armor, Medium, Bulky, 120 sp, Rare.** Also absorbs Half-Plate as a reskin.

If approved, these become two new rows in *Hardware*'s core Armor table (currently 4 entries → 6). I haven't touched that file — flagging it here for your call rather than silently expanding the core table.

**New minor add-ons (low-risk, not core-table changes):**

| Item | Cost | Availability | Effect |
|---|---|---|---|
| Armor spikes | 15 sp | Scarce | When an enemy loses a Grab or Shove Clash against you, they suffer 1 Impact from the spikes. |
| Gauntlet, locked | 5 sp | Common | Advantage on Prowess checks to resist being disarmed. |
| Shield spikes | 8 sp | Common | Shove actions made with this shield deal +1 Impact on a win. |

**On Max Dex Bonus / Armor Check Penalty / Arcane Spell Failure:** these don't need conversion at all. I&M already expresses all three concepts through the Bulky and Restricted tags on the existing table — Bulky already imposes -1 to Athletics, Stealth, *and* Arcana (i.e., ASF is already covered), and Restricted already kills Arcane casting outright and cuts Movement by 10 ft. Reintroducing a separate numeric penalty stack on top of that would just recreate the exact granular bookkeeping the system was built to avoid. Leave it alone.
